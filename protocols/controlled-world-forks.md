# Controlled world-fork protocol

Status: **frozen before execution**

## Question

When one evaluator-owned world law is changed at a time, does ChemWorld hold the public task
contract, typed action sequence and replay semantics fixed while producing the registered
parent–child divergence?

## Frozen units

Six matched parent–child pairs cover the declared intervention classes. Each pair is exercised
with the same provider-free policy and produces four traces, for 24 traces in total. The public
task and action interfaces are invariant across each pair; only the declared private law differs.

## Pass conditions

- All six pairs and all 24 traces complete.
- No provider call occurs.
- Parent and child retain the same public contract and typed action sequence.
- The registered divergence gates pass for every pair.
- Parent and child traces replay exactly.

This finite protocol qualifies controlled counterfactual execution for the registered forks. It
does not establish exhaustive world coverage, agent performance or physical-laboratory validity.
