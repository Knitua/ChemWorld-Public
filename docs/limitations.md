# Limitations and safe interpretation

ChemWorld is a software-model environment for controlled agent research. It is not a protocol generator for physical laboratory work.

- Qualification covers finite registered tasks, compositions, probes and world forks—not all chemistry.
- Public observations are generated by the declared software models and instruments; they do not certify experimental fidelity.
- Tutorial recipes demonstrate interface use. They are not optimized procedures or recommendations for real materials.
- Exact replay means the software trace is reproducible under the release contract. It does not reproduce laboratory uncertainty.
- Controlled hidden components are evaluator-owned mechanisms for research design. Agents must not receive direct hidden-state access.

No manuscript files, unpublished results, development matrices, raw provider responses or private evaluator configuration are included in this repository.

For exact release claims, use the [Evidence](evidence.md) page and `scripts/verify_release.py`.
