# 展示世界

ChemWorld 提供一组可互操作的实验世界，而不是十五个彼此孤立的模拟器。任务从同一套有类型操作语言中选择不同切片，并组合所需的装置、物料、仪器和评分能力。

## 世界家族

| 家族 | 公开任务与问题 |
| --- | --- |
| 反应与终检 | `reaction-to-assay`、标准优化、安全约束优化、机理解释 |
| 分离与纯化 | 分配行为发现、反应到纯化、纯度–收率权衡 |
| 结晶 | 晶种冷却、分离以及纯度、收率和粒径权衡 |
| 蒸馏 | 反应后的挥发性产物回收 |
| 流动化学 | 在有边界过程控制下优化几何解析 PFR |
| 电化学 | 溶剂/电解质选择与有选择性的电荷、能效转化 |
| 表征与规划 | 平衡表征、低预算表征与 Tool-Agent 规划 |

Public v0.4 注册任务总数为 15。“Showcase”表示平台广度与教学价值，并不自动赋予每个任务正式 Agent 比较结论。

## 共享实验语言

根据任务，同一运行时可以开放：

- 加溶剂、试剂、催化剂、相或萃取剂等物料操作；
- 加热、混合、静置、结晶、蒸馏、流动反应或电解等过程操作；
- 分相、洗涤、干燥、蒸发和收集等后处理操作；
- HPLC、GC、光谱、伏安与 final assay 等公开仪器；
- 终止和合同有效 closeout 等生命周期操作。

`available_actions()` 和动作 Schema 随状态变化。世界不是“所有按钮永远可点”的菜单：装置、物料、任务权限和预算共同决定下一步能否提交。

## 组合资格测试

本版本验证了 64 个参考任务–世界单元和 52 个生成组合。测试覆盖接口兼容、确定性回放、有界响应、守恒与任务级执行。这些数字是软件组合系统的覆盖证据，不等于 116 次独立化学验证。
