# 适用边界与安全解释

ChemWorld 是用于受控 Agent 研究的软件模型环境，不是生成真实实验室操作规程的工具。

- 资格测试只覆盖有限的注册任务、组合、探针和 world fork，不代表全部化学空间。
- 公开观测由声明的软件模型与仪器生成，不构成实验保真度认证。
- 教程 recipe 只演示接口使用，不是优化实验方案，也不是对真实材料的操作建议。
- 精确回放表示软件轨迹在发布合同下可复现，不代表复现真实实验的不确定性。
- 受控隐藏组件属于评测者的研究设计工具，Agent 不应获得直接 hidden-state 访问。

仓库不包含论文文件、未公开结果、开发实验矩阵、原始 Provider 响应或私有评测配置。

准确的发布声明请以[证据](evidence.md)页面和 `scripts/verify_release.py` 为准。
